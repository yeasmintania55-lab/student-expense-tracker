# Student Expense & Budget Tracker

A simple and interactive web application that helps students manage their daily expenses and monthly budgets.

## About the Project

The Student Expense & Budget Tracker is a frontend web development project designed to help students track their spending, organize expenses by category, and monitor their monthly budget.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

## Features

- Add new expenses
- Edit and delete transactions
- View total expenses
- Set a monthly budget
- Track remaining balance
- Search transactions
- Filter expenses by month
- View category-wise expense summaries
- Visualize expenses using a pie chart
- Export transactions as CSV
- Dark mode and light mode
- Save data using LocalStorage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start managing your expenses!
